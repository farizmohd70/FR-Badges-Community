# FR Badges: community made

Badges made and shared by people on the [FR Badges site](https://farizmohd70.github.io/FR-Badges/community.html).

- `badges/` holds the badge images (PNG).
- `index.json` is the list the site reads: each badge has an id, a name and its regex pattern.

People add badges from the site (**Make a badge**, then **Share with the community**). A small Cloudflare Worker saves them here, so please do not edit these files by hand, except to remove a badge.

## Removing a badge

Delete its entry from `index.json` (and, if you like, its image from `badges/`). It disappears from the site within a few minutes.

## Rules for shared badges

Keep them friendly. Do not copy other people's logos or brand artwork. Badges that break these rules are removed.
